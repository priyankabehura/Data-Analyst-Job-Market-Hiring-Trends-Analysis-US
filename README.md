# Data-Analyst-Job-Market-Hiring-Trends-Analysis-US
Data Analyst Job Market &amp; Hiring Trends Analysis (US). Kaggle data (lukebarousse, 58,775 postings, Nov 2022 – Apr 2025) cleaned and transformed in Power Query (duplicates, text trimming, custom columns, skills split into rows) and visualised in a Power BI dashboard: top skills, salary, seniority, companies, hiring trends.
